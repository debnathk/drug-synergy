### **DrugComb**

* **Type** : Web-based data portal and analysis platform
* **Primary Focus** : Interactive visualization and computation of drug combination synergy scores
* **Functionality** : Provides computational tools for users to upload, analyze, and annotate their own drug combination dose-response data
* **Emphasis** : Cancer-specific drug combinations with focus on dose-response matrices
* **Release** : Published in 2019
* **Website** : [https://drugcomb.fimm.fi/](https://drugcomb.fimm.fi/)

### **DrugCombDB**

* **Type** : Comprehensive drug combination database
* **Primary Focus** : Large-scale curation of drug combinations from multiple sources (HTS assays, literature, FDA Orange Book)
* **Data Scale** : Contains 448,555 drug combinations with 6,055,926 quantitative dose responses covering 2,887 unique drugs and 124 human cancer cell lines
* **Emphasis** : Comprehensive data collection and pre-computed synergy scores
* **Release** : Published in 2020 (after DrugComb)
* **Website** : [http://drugcombdb.denglab.org/](http://drugcombdb.denglab.org/)

### **Summary**

* **DrugComb** = Interactive analysis platform (you bring your data + use their tools)
* **DrugCombDB** = Large curated database (they provide the data with computed scores)

Both resources complement each other - DrugComb is ideal for analyzing your own experimental data, while DrugCombDB is excellent for exploring existing drug combination data at scale.
