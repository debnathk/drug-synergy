# Drug Synergy Prediction using Attention-Based Multi-Modal Fusion

## Problem Statement

Predicting the synergistic effects of drug combinations is a critical challenge in cancer treatment, where combination therapies can significantly improve patient outcomes compared to single-drug treatments. However, experimentally testing all possible drug pairs across different cancer cell lines is prohibitively expensive and time-consuming—with thousands of approved drugs and hundreds of cancer cell lines, the combinatorial space is vast. Current computational approaches often rely on simple feature concatenation or shallow models that fail to capture the complex, non-linear interactions between drugs and the biological context of the cell line. There is a need for deep learning methods that can effectively integrate heterogeneous data sources (drug molecular structures, multi-omics cell line profiles) and learn meaningful representations of drug-drug-cell interactions to accurately predict synergy scores.

## Proposed Methodology

We propose an attention-based multi-modal fusion architecture for drug synergy prediction that integrates pre-trained drug molecular embeddings with cell line multi-omics data (mRNA, miRNA, and proteomics). The model consists of three key components: (1) **Omics Fusion Module** — individual encoders project each omics modality to a shared embedding space, followed by self-attention to learn cross-modality relationships and capture which biological signals are most relevant; (2) **Drug-Omics Cross-Attention** — the two drug embeddings and the fused omics embedding are combined via multi-head self-attention with residual connections, enabling the model to learn how each drug interacts with the cell line's biological state and with each other; (3) **Prediction Head** — the attention-enriched representation is passed through an MLP to predict the synergy score (ZIP metric). Drug representations are obtained from MolFormer-XL, a pre-trained molecular language model, allowing the model to leverage rich chemical knowledge without task-specific drug encoding. This architecture enables interpretability through attention weight analysis, revealing which omics modalities and drug-cell interactions drive the predictions.
